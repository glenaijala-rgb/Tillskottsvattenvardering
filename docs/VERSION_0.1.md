# Version 0.1

Git-tagg: v0.1. Programversion: 0.1 (frontendpaket 0.1.0).

Denna utgåva innehåller lokal projektlagring i SQLite, värdering av åtgärder, integrerade beräkningsstöd och fältförklaringar, startvärden med källinformation, bortval för ej aktuella poster, fältkopplade fel, automatisk snabb regnpåverkan, tusentalsavgränsade belopp samt direktkontroll av effekter mot nuläget.

Beräkningsmotorns separata version är fortsatt 1.1.0 för att bevara spårbarheten för sparade resultat. SQL-schemaversionen är 1.

Verifiering och kvarstående frågor framgår av VERIFIERING.md och BESLUT_OCH_FRAGOR.md. Microsoft Excel-kontroll och slutlig metodgranskning av ARV kvarstår.
